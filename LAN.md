# Игра вдвоём по точке доступа (Android)

Нужны **два телефона с CARANTIN APK 4.5**. Интернет, аккаунт и внешний сервер не требуются. В одной локальной сессии участвуют ведущий и напарник.

1. Включите точку доступа на телефоне ведущего и подключите к ней второй телефон. Откройте APK на обоих телефонах.
2. У ведущего: главное меню → **«Играть вместе по точке доступа»** → выберите **«Сюжет вдвоём»** или **«Открытый мир»** → **«Создать игру»**. Для продолжения сюжета можно выбрать **«Создать из сохранения»**. Внизу появится локальный IP ведущего и порт `8765`, например `192.168.43.1:8765`.
3. У напарника: **«Играть вместе по точке доступа»** → введите IP ведущего **без порта** → **«Подключиться по IP»**. Режим и мир загрузятся автоматически.
4. Оба игрока могут передвигаться, стрелять и сражаться с заражёнными. В сюжете оба видят текущую цель, диалоги и поездку между секторами; напарник тоже может исследовать улики и защищать объект. Ведущий делает выборы в диалогах и ведёт машину через КПП. После гибели напарник возрождается; гибель ведущего завершает забег.

**Сохранения.** Ведущий может сохранить кампанию на своём устройстве через паузу, а позже создать новую совместную игру из этого сохранения. Сохранение напарника не перезаписывается; посреди активной сессии загружать слот нельзя. В открытом мире прогресс сессии отдельно не сохраняется.

**Производительность.** Во время совместной игры на телефоне напарника автоматически снижается разрешение рендера и отключаются тяжёлые световые эффекты, а радар обновляется реже. Положение противников и пуль передаётся только поблизости от напарника. Ведущий рассчитывает столкновения, урон и сюжетное состояние; при проблемах связи игра использует последнее состояние, не накапливая очередь устаревших кадров. Настоящие физические телефоны могут показать иное поведение, чем тесты в браузере.

Если соединение не устанавливается, проверьте адрес точки доступа в настройках ведущего (некоторые телефоны первыми показывают другой сетевой интерфейс), разрешите подключение других устройств, отключите VPN/изоляцию клиентов и убедитесь, что на обоих устройствах APK 4.5. При выходе ведущего сессия заканчивается. GitHub Pages не может создать локальный сервер — веб-версия остаётся одиночной.
